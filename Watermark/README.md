# Watermark 1.4.0

为 Typecho 正文中的本地上传图片动态添加图片或文字水印，支持单点/全图平铺、旋转、透明度、图片排除、最小尺寸及静态缓存。

## 环境要求

- Typecho 1.2 或 1.3
- PHP 7.4 或 PHP 8.x
- GD 扩展
- 使用文字水印时，GD 需要 FreeType 支持

## 使用方法

1. 将插件目录命名为 `Watermark` 并放入 `usr/plugins/`。
2. 在 Typecho 后台启用插件并保存水印设置。
3. 插件仅处理 `usr/uploads/` 内的 GIF、JPEG、PNG、WebP 图片。
4. 动态 GIF 保持原图，不添加水印。

## 平铺与透明度

- `水印布局` 默认为“单点”，升级后保持原有位置行为；选择“全图平铺”后，水印会交错覆盖整张图片。
- `旋转角度` 支持 -180 到 180，正数逆时针旋转，同时作用于图片和文字水印。
- `平铺水平间距`、`平铺垂直间距` 控制相邻水印之间的空白像素。
- `图片透明度` 保留原有 `vm_alpha` 配置，只作用于图片水印。
- `文字透明度` 使用独立的 `vm_text_alpha` 配置，只作用于文字水印。
- 两种透明度均为 0 时不透明、100 时全透明。

推荐的平铺配置可以从以下参数开始，再根据水印尺寸调整：

```text
旋转角度：-30
水平间距：100
垂直间距：80
文字透明度：60
```

## 图片限制

`原图最小宽度`和`原图最小高度`按上传原图尺寸判断。任一尺寸低于配置值时保持原图，设置为 0 表示不限制。

图片排除列表每行一条规则，空行和以 `#` 开头的行会被忽略，支持以下格式：

```text
# 排除整个上传子目录
/usr/uploads/avatar/

# 相对于 usr/uploads 的路径
2026/qrcode.png
2026/private/*

# 匹配任意目录中的文件名
logo-*
*-no-watermark.png
```

规则支持 `*` 匹配任意字符、`?` 匹配单个字符。排除和最小尺寸判断同时用于正文 URL 改写与水印 Action，不能通过直接访问 Action 绕过。

## 缓存

水印缓存独立保存在：

```text
usr/cache/watermark/
```

插件设置页提供带安全令牌的清理入口，只会删除该目录内由插件生成的缓存文件。

布局、角度、间距、图片/文字透明度、排除列表和最小尺寸均进入缓存键；设置变化后会生成新的缓存，不会误用旧配置的图片。

旧版本曾将缓存写入 `usr/img/`，且清理时会删除该目录中的全部文件。1.3.0 不会自动删除该目录中的任何内容；升级后请人工区分并处理旧缓存，避免误删站点 Logo、OG 图片等资源。

## 1.4.0 变更

- 增加全图交错平铺，图片和文字水印均支持旋转。
- 保留 `vm_alpha` 的图片透明度语义，并增加独立的 `vm_text_alpha` 文字透明度。
- 增加横纵平铺间距配置，并限制极端配置下的最大绘制量。
- 增加图片排除列表，支持完整路径、上传目录相对路径、文件名和通配符。
- 增加原图最小宽高限制。
- 缓存键纳入全部新增配置，默认配置保持原有单点水印行为。

## 1.3.0 变更

- 兼容 Typecho 1.2/1.3 的命名空间内容钩子。
- 在 Markdown 渲染为 HTML 后统一处理图片。
- 限制水印源文件必须位于 `usr/uploads/`，并为公开水印地址增加 HMAC 签名。
- 使用独立缓存目录，清理缓存时增加管理员权限和安全令牌校验。
- 修复 PHP 8 下空配置、GD 资源销毁及 EXIF 缺失导致的错误。
- 增加 JPEG、WebP 支持，并安全跳过动态 GIF。
- 缓存键包含原图、字体、水印图片的内容指纹及水印配置，文件或设置变化后自动生成新缓存。
